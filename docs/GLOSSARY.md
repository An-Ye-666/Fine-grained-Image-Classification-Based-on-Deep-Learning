
# 术语表

| 术语             | 通俗解释                       |     |
| -------------- | -------------------------- | --- |
| 类别 Class       | 模型需要识别的目标，本项目共有 37 个宠物品种   |     |
| 标签 Label       | 一张图片对应的真实类别编号              |     |
| Tensor         | 多维数组，图片和模型中间结果都用 Tensor 表示 |     |
| Batch          | 一次送入模型的一组样本，例如 32 张图片      |     |
| Epoch          | 模型完整看过一遍训练集                |     |
| Iteration      | 处理一个 Batch 的一次前向和反向过程      |     |
| 前向传播           | 图片经过模型得到预测结果               |     |
| 损失 Loss        | 预测结果与真实标签之间的差距             |     |
| 反向传播           | 根据 Loss 计算参数应该怎样调整         |     |
| 优化器            | 根据梯度更新模型参数的算法              |     |
| 学习率            | 每次更新参数时的步长                 |     |
| 参数或权重          | 模型内部通过学习更新的数值              |     |
| Baseline       | 作为对照的基础方案                  |     |
| 消融实验           | 只改变一个因素，观察它是否有效            |     |
| 过拟合            | 模型记住了训练集，但面对新数据效果变差        |     |
| Checkpoint     | 保存下来的模型参数文件                |     |
| Logits         | 模型输出的原始类别分数，尚未经过 Softmax   |     |
| Softmax        | 把类别分数转换为总和为 1 的数值          |     |
| Top-1 Accuracy | 最高分类别是否预测正确                |     |
| Top-5 Accuracy | 正确类别是否出现在前五个候选中            |     |
| Macro-F1       | 先计算每类 F1，再进行等权平均           |     |
| 混淆矩阵           | 展示真实类别和预测类别对应关系的表格         |     |
| Grad-CAM       | 用颜色热力图显示模型主要关注图片的哪些区域      |     |
| 数据泄漏           | 测试信息在训练阶段被模型间接看到，导致成绩不可信   |     |
| 分层划分           | 保持每个类别在训练、验证、测试中的比例接近      |     |
| 随机种子           | 控制随机过程，使实验更容易复现            |     |
| 可复现            | 其他人按说明能够重新得到相近结果           |     |
