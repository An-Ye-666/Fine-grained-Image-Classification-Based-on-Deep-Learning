# 数据模块说明

这个目录把数据处理拆成四个容易理解的步骤：

```text
manifest.py
  → 读取官方清单，生成固定的 train / val / test 划分

transforms.py
  → 规定图片怎样调整大小、裁剪、翻转和归一化

dataset.py
  → 每次读取一张图片，返回 [3, 224, 224] 的 Tensor 和标签

dataloaders.py
  → 把多张图片组合成 [32, 3, 224, 224] 的 batch
```

关键约定：

- 只有官方 7,349 张图片参与划分；
- 图片目录中的额外 41 张图片不参与实验；
- 固定使用 `seed=42`，划分结果保存在 `artifacts/splits/`；
- 官方类别编号是 1 到 37，Dataset 返回给模型的标签转换为 0 到 36；
- 验证集和测试集不使用随机裁剪或随机翻转。
